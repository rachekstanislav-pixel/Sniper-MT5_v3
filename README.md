# Sniper MT5 v3 — GOLD / M5

Полный советник с встроенным виртуальным новостным блоком:
**[Sniper_Manager_v3_6_5_NEWS_VIRTUAL.mq5](Sniper_Manager_v3_6_5_NEWS_VIRTUAL.mq5)**.
Включает исходный BASE 3.65. Один файл MQ5, дополнительные include-файлы для него не нужны.

## Запуск

1. Скачайте весь репозиторий: **Code → Download ZIP**, распакуйте.
2. На компьютере с MT5 установите Python 3.10+ и запустите `news/start_news_windows.cmd`.
3. Проверьте `http://127.0.0.1:8765/events`: `errors` должен быть пустым, публикации — фактически полученными.
4. Поместите полный MQ5 в `MQL5/Experts`, скомпилируйте MetaEditor.
5. В MT5 разрешите WebRequest для `http://127.0.0.1:8765`.
6. На **демо-счёте** установите новый советник на GOLD/XAUUSD M5 вместо прежнего.

**BASE сохраняет возможность реальной торговли. Только новостные сделки виртуальны.**
Не устанавливайте две версии одновременно с одинаковым Magic.
`News_Enabled` управляет только новостным экспериментом, не автоторговлей BASE.
При недоступном сервисе новостная строка показывает WAIT; BASE продолжает свою работу.

Сбор источников в текущей облачной среде пока блокируется сетью. Сбор реальных публикаций,
актуальность RSS, условия использования, компиляция MetaEditor и фактический MT5-прогон
**не подтверждены**. Интеграция кода завершена; полностью рабочим новостным сбором это ещё не является.

[Подробная инструкция: сервис, replay, гипотеза ФРС и ограничения](news/README.md).

Исходный `Sniper_Manager_v3_6_5_BASE_ATR_RESTORED_VISUAL.mq5` и `MetaTrader5_v1.txt`
сохранены. TXT — старый исходник, для установки не нужен; встроенный в него Telegram-токен
следует отозвать. Новый новостной код ключей не требует.
