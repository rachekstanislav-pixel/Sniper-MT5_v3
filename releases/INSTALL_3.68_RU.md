# Sniper Manager 3.68 — только исправление задвоения визуала

Полный файл: Sniper_Manager_v3_6_8_VISUAL_FIX.mq5.
Торговые функции и новостные блоки идентичны 3.67. Входные параметры и их значения
по умолчанию не изменены. Единственное изменение поведения — имена/очистка объектов
отрисовки при запуске, смене символа/периода, восстановлении шаблона.

Почему задваивалось: старые версии создавали случайный префикс при каждом запуске.
Объекты прошлых запусков и объекты, скопированные шаблоном с GOLD на BTC, не попадали
в очистку текущего экземпляра. На активном рынке новый слой обновлялся поверх старого.

Теперь используется стабильный префикс в пределах графика. Перед отрисовкой удаляются
только распознанные визуальные объекты Sniper: старый S36_<8 hex>_<известное имя> и
новый SN368V_<известное имя>. Очистка касается только текущего графика.
Ручные линии, произвольные объекты других инструментов и соседние графики не очищаются.
Остальная визуальная логика (структуры, сигнальные стрелки, панели, уровни) сохранена.

## Установка с сохранением текущих параметров

1. На текущем графике F7 → Входные параметры → Сохранить: сохраните свой SET.
2. Скопируйте новый MQ5 в MQL5/Experts, откройте MetaEditor и скомпилируйте F7.
3. При замене запущенного советника учитывайте его прежний OnDeinit: как и в 3.67,
   он может отменять собственные отложенные заявки. Исправление визуала этого не меняет.
   Обновление удобнее проводить, когда советник не управляет активными заявками.
4. Установите только один экземпляр новой версии вместо прежней и загрузите СВОЙ
   сохранённый SET. Удалять объекты вручную или применять пустой шаблон не требуется.
5. Проверьте BTC/M5 на активных тиках и при смене периода/символа: должен оставаться
   один актуальный слой панели, NEWS и уровней. Точные старые имена Sniper очищаются
   автоматически; нераспознанные объекты намеренно не удаляются.

Не загружайте приложенный NEWS_ONLY_SYNTHETIC_3.67.set на обычный график:
он только для прежнего синтетического теста. Приложен без изменений и совместим с 3.68.
Сервис Python остался 0.5.0, обновлять его и базу данных для этого исправления не нужно.

## Валидация

35 автоматических проверок прошли. Отдельная проверка восстанавливает файл 3.67
после удаления только визуального патча и изменения номера версии: весь остальной
код совпадает. C++ mock-harness проверяет миграцию старых объектов, повторную
инициализацию и сохранность чужих объектов/другого графика.
Это не MetaEditor-компиляция и не просмотр живого BTC-графика в MT5. Новая ревизия
должна быть подтверждена на терминале пользователя; фактический внешний вид пока
не проверен. Прошлый 3.67 тестерный прогон отдельно подтверждён присланными логами.

Для тестерных новостных сделок см. INSTALL_TESTER_3.67_RU.md. Все ограничения исходного
новостного эксперимента сохраняются: синтетические fixtures, неполная историческая
база новостей, неустранённый BLS 403, направления только по изменениям ставки ФРС.
