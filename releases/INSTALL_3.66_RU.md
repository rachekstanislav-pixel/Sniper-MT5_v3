# Sniper Manager 3.66 / News service 0.5.0

Полный советник: Sniper_Manager_v3_6_6_NEWS_VIRTUAL.mq5.
Версия 3.66 объединяет неизменённую торговую базу 3.65 и исправления новостей 0.5.0.
EX5 не приложен: скомпилируйте MQ5 в MetaEditor. Дополнительные MQH этому файлу не нужны.

## Обновление Windows / VPS

1. Остановите старый сервис Ctrl+C. Если спросит завершение пакетного файла — Y, Enter.
2. Распакуйте весь архив в новую папку.
3. Запустите news/start_news_windows.cmd на том же компьютере Windows, где MT5.
   Python 3.10+ должен быть установлен. Дополнительных pip-пакетов нет.
   Сервис использует прежнюю базу %LOCALAPPDATA%/sniper-news.sqlite3: не удаляйте её.
4. Откройте http://127.0.0.1:8765/status. Версия должна быть 0.5.0.
5. MT5 → Файл → Открыть каталог данных → MQL5/Experts. Скопируйте новый MQ5 туда.
6. Откройте новую копию в MetaEditor и нажмите F7. Компиляция этой ревизии автором
   в MetaEditor ещё не подтверждена: при ошибках сохраните их текст.
7. Удалите прежний экземпляр советника с графика; две версии одновременно не запускайте.
8. MT5 → Настройки → Советники: разрешите WebRequest для http://127.0.0.1:8765.
9. Установите 3.66 на демо GOLD (Gold vs US Dollar, не акции Barrick) / M5.
   Для тестирования только виртуальных новостей:
   EnableAutoTrade=false; DiagnosticMode=false; News_Enabled=true; News_Replay=false.
   News_Enabled отображается как «Virtual news only; does not gate BASE trading».
   «Алготрейдинг» оставьте выключенным. Настройки остальных модулей не меняйте.
10. На графике смотрите строку NEWS; состояния подробнее видны на /status.

ВАЖНО: основной советник сохраняет возможность реальной торговли. Новостные входы
только виртуальные. При включении основной автоторговли это не «бот без сделок».
SET для запуска не требуется; при замене версии сравните свои прежние параметры вручную.

## macOS

MT5 для macOS работает через Wine. Для запуска сервиса на самом Mac:
откройте Terminal в папке news и выполните:

    mkdir -p "$HOME/Library/Application Support/SniperNews"
    python3 service.py --db "$HOME/Library/Application Support/SniperNews/news.sqlite3" --port 8765

Окно оставьте открытым. Если MT5 находится на удалённом Windows VPS, запускайте сервис
на VPS, а не на Mac: localhost у каждого компьютера свой. Mac/Wine-путь ещё не проверен.

## Что исправлено и что не обещается

Пустые старые разборы FED повторно анализируются; временный WAIT не теряет ожидающий ID.
Поддержаны Unicode-дроби ставки, исходные ответы сохраняются в SQLite для диагностики.
Время опубликования не обновляется: старые новости не превращаются в новые сигналы.
Направления только для однозначного raise/lower ставки FED с последующим подтверждением
котировкой GOLD. BLS/BEA пока collection-only; BLS HTTP 403 остаётся нерешённым.
Изменения ставки редкие: ежедневные сигналы не обещаются. Прибыли не обещаем.
31 автоматическая проверка и отдельный синтетический HTTP smoke прошли; это не новая
MetaEditor-компиляция и не прогон MT5. Синтетические fixtures не являются реальными новостями.
Виртуальные результаты не учитывают комиссии/дополнительное проскальзывание/задержку.
Перезапуск не восстанавливает открытую виртуальную позицию: она остаётся UNRESOLVED.

Логи новостей: Terminal Common/Files, имя из News_JournalFile.
SHA256SUMS.txt содержит контрольные суммы всех вложенных файлов, кроме самого списка.
