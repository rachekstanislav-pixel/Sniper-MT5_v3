# Sniper Manager 3.67 — новостные приказы только в Strategy Tester

В архиве полный советник Sniper_Manager_v3_6_7_NEWS_TESTER.mq5, готовый
NEWS_ONLY_SYNTHETIC_3.67.set, два синтетических события и сервис 0.5.0.
EX5 не приложен: нужна компиляция MetaEditor. Все новые исходники встроены в один MQ5.
Код остальных сигналов BASE/EMA/Compression/OTE/Sweep/AI сохранён. Новый режим
требует выключенной основной автоторговли; дополнительные выключатели заданы SET.

## Первый тест — без ручного поиска входных параметров

1. Скопируйте MQ5 в MT5 → Файл → Открыть каталог данных → MQL5/Experts.
   Откройте именно эту копию в MetaEditor, F7. Автор не запускал компиляцию MetaEditor
   этой ревизии: при ошибках пришлите весь список с номерами строк.
2. Поместите CommonFiles/SYNTHETIC_20261106.tsv из архива в:
   %APPDATA%/MetaQuotes/Terminal/Common/Files
   Файл синтетический: это не реальные решения ФРС. Не менять время публикаций.
3. MT5 → Ctrl+R. Советник: Sniper_Manager_v3_6_7_NEWS_TESTER.
   GOLD (золото/USD, не акции Barrick), M5, даты 06.11.2026–07.11.2026.
   Каждый тик на основе реальных тиков, оптимизация отключена, визуализация включена.
   Только локальный агент. Депозит/плечо подберите как на своём демо; например $10000/1:100.
4. Вкладка Параметры → правая кнопка по таблице → Загрузить →
   NEWS_ONLY_SYNTHETIC_3.67.set из распакованного архива.
   В некоторых сборках кнопка «Загрузить» находится прямо в окне параметров.
   SET задаёт входные параметры, но не символ, даты или модель из пункта 3.
5. Убедитесь, что News_TesterOrders=true, EnableAutoTrade=false, DiagnosticMode=false.
   DiagnosticMode не должен быть true: этот режим исходного бота запрещает приказы.
   Прочие торговые модули отключены SET. Их код и обычные значения по умолчанию не менялись.
6. Старт. Сервис Python в этом replay не нужен. Тестер исполняет рыночные news-приказы,
   выставляет SL/TP и закрывает позицию после 60 секунд при наличии следующего тика,
   если SL/TP не сработали раньше. На новостной строке будет NEWS [TESTER ORDERS].
7. После теста пришлите отчёт/сделки тестера, его Журнал и файл Common/Files/TESTER_NEWS_367.tsv.

## Что задано SET

Только News_TesterOrders включён; Magic 9367001, фиксированный объём 0.01 лота.
Некорректный для брокера объём не округляется вверх — заявка отклоняется с записью в журнал.
Одна позиция по символу; смешивание с существующей позицией запрещено, в том числе на netting.
Для тестерных приказов нельзя включить EnableAutoTrade или DiagnosticMode: инициализация
будет отклонена, чтобы не смешивать другие сигналы и не нарушать диагностический запрет.
Оптимизация также отклоняется: независимые прогоны используют общий файл журнала.

Синтетический BUY 6 ноября в 12:00 UTC и SELL в 13:00 UTC. Файл не содержит консенсуса
или реальных решений ставки. Исторические котировки поступают из брокерского тестера.
Подтверждение 1 секунда / 1 point; SL 500 points, цель 1000, hold 60 секунд,
максимальный спред 1000 points. Это упрощённые технические параметры, не рекомендации.
Вход не гарантирован: без подтверждения цены, с недопустимым спредом или при отказе
брокерской проверки сделки не будет. Причину смотрите в Журнале и TESTER TSV.

News_ServerUTCOffsetSeconds=7200 — ЯВНОЕ ПРЕДПОЛОЖЕНИЕ UTC+2 для исторических котировок
6 ноября. Если сервер брокера в этот день имел другое смещение, задайте действительное.
Тогда при UTC+2 синтетические события появляются на графике в 14:00 и 15:00.
Сам часовой пояс Windows не доказывает смещение исторических котировок.

News_TesterFreshJournal=true очищает ТОЛЬКО заданный журнал с basename TESTER_ в Common/Files
при независимом тесте. Не задавайте для него важный старый журнал. Live-журналы и SQLite
не очищаются. Публикация даёт максимум один вход за прогон, повторы ID пропускаются.
Не запускайте несколько тестов одновременно с одним журналом.

## Выходы и результаты

SL/TP исполняет сам тестер; цены/комиссии/свопы/депозит и сделки проверяйте в его отчёте.
Таймаут посылает закрывающую заявку только для собственной позиции по отдельному Magic.
TSV содержит TESTER_OPEN и TESTER_CLOSE с ID события; points не равны денежному PNL.
Частичное исполнение и комиссии оценивайте по торговому отчёту, не по последней строке points.
Открытые позиции при окончании теста могут закрываться самим тестером; это отдельно видно
в отчёте. Прерывание теста/перезапуск не восстанавливает связь текущей news-позиции с ID.
Тестировать рекомендуется одним непрерывным прогоном. Если позиция не удаётся сверить с
историей, новые входы блокируются до сверки, а статус сообщает reconcile.

## В работающем терминале

News_TesterOrders по умолчанию false. При включении вне Strategy Tester запуск отклоняется,
а каждый OrderSend дополнительно защищён проверкой MQL_TESTER. Live-новости только виртуальные.
Не загружайте этот SET на обычный график. Основная стратегия по-прежнему умеет торговать
при своих разрешённых настройках; это не изменение её логики.
Сервис 0.5.0 в news/ приложен без изменения. Его обновлять с 0.5.0 не требуется.
Для обычного сбора на Windows запустите news/start_news_windows.cmd, диагностика /status.
Python и MT5 должны работать на одном компьютере. SQLite и live-журналы сохраняйте.

## Доказательства и ограничения

33 автоматические проверки прошли, включая source-derived C++ harness разрешений,
запрета приказов в live и неприкосновенности исходных торговых функций. Это НЕ компиляция
MetaEditor и НЕ фактический прогон MT5. Брокерские исполнения этой версии ещё не подтверждены.
Полного исторического архива реальных публикаций нет; синтетический тест проверяет механику,
не доходность новостной торговли. Направления реальных новостей по-прежнему только для
однозначного raise/lower ставки ФРС; BLS/BEA collection-only. BLS 403 не исправлен.
